# X2 report: evolution on the levers X1 kept (spec 9.4, 9.6b)

How to read it, before any comparison:

- **Arm to arm only.** X2 is read arm to arm only, not against X1 on wins: round 1 trials the whole idea result (O50), where X1's slice trialled the marker's top 3 and the engine's default is 3 a round.
- **The noise band (O51 as amended).** Each library is read against its own twin gap where a twin exists: a difference from X2-0 counts only beyond that library's gap between X2-0 and X2-0', in points of combine gain and on the kept count, and the gap itself is inside. Only a library without a twin takes O51's fixed band: there an arm-to-arm difference under about 4 points of combine gain, or under 1 on the kept count, is noise (O51).
- **Reading the arms (O52).** Per library with a twin, a kept-count difference within its twin gap is inside the measured band, one beyond it is outside the measured band, not significant, and two or more beyond it are outside the measured band (with a twin gap of 0, O52's gaps of 0, 1 and 2 or more). Per arm, against X2-0 over the libraries both ran: the kept count is a sign count, and the arm keeps more only if it keeps more on more libraries than it keeps fewer, keeps fewer only if it keeps fewer on more libraries than it keeps more, else no difference; the combine's mean difference is better only when it exceeds the twin's mean absolute gap, worse only when it is below minus that gap, else within the twin's mean gap. Each call says how many libraries it rests on. No single library decides (O52).
- **Delivered gain.** A combine's gain counts only when it held: a run with no held combine delivers 0 in every difference and mean.
- **Sources:** each results file, its SHA-256 prefix and its dispatches.
